# Solar Forecasting & Microgrid Management

Семестровый проект по дисциплине «Прикладные задачи машинного обучения».

## Цель

Разработать систему прогнозирования выработки солнечной генерации
и управления накопителем энергии (ESS) для микросети.

## Команда

- **Участник 1 (Data)** — сбор данных, EDA, Feature Engineering
- **Участник 2 (ML)** — прогнозирование генерации (Блок А)
- **Участник 3 (RL)** — RL-диспетчер (Блок Б), Dashboard

## Структура

- `data/` — данные
- `notebooks/` — ноутбуки
- `src/` — Python-модули
- `models/` — модели
- `results/` — графики и метрики
- `docs/` — документация
